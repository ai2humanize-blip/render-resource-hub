What is Pi Cryptocurrency?

Pi Cryptocurrency is the native token of the Pi Network, which aims to create a decentralized digital currency that can be mined using a mobile app. The project was launched by a team of Stanford graduates with the vision of making cryptocurrency mining accessible to everyone, regardless of their technical expertise or financial resources. The Pi Network operates on a consensus algorithm called Stellar Consensus Protocol (SCP), which is designed to be energy-efficient and scalable.
